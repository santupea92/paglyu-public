
PASOS PARA SUBIR A GITHUB PAGES:

1. Andá a https://github.com/ y creá un nuevo repositorio.
2. Subí todos los archivos que están dentro de esta carpeta (no la carpeta entera).
3. Entrá a Settings > Pages.
4. En Source, elegí 'Deploy from a branch' y seleccioná 'main' y carpeta raíz ('/').
5. Guardá y esperá unos segundos. Te va a dar un link como:
   https://tuusuario.github.io/nombredelrepo

¡Listo! Tu sitio ya está online.
